# ChatDiWa

อ่านแชท TikTok LIVE ออกเสียงให้อัตโนมัติ เสียงเข้าสตรีมผ่าน OBS Browser Source — **ไม่ต้องติดตั้ง virtual audio cable หรือโปรแกรมเสียงเพิ่มเติมใดๆ**

## เตรียมตัวก่อนเริ่ม (ทำครั้งเดียว)

1. ติดตั้ง **Node.js** (เวอร์ชัน 18 ขึ้นไป): ไปที่ https://nodejs.org แล้วโหลดตัว "LTS" มาติดตั้งตามปกติ (กด Next ไปเรื่อยๆ)
2. เปิดโปรแกรม **Terminal** (Windows: กด `Win`, พิมพ์ `cmd` หรือ `PowerShell`, กด Enter)

## เริ่มใช้งาน

ในหน้าต่าง Terminal พิมพ์คำสั่งนี้แล้วกด Enter:

```
npx github:Babyferret/chatdiwa
```

รอสักครู่ (ครั้งแรกจะโหลดไฟล์ที่จำเป็น) โปรแกรมจะถาม **TikTok username** ของคุณ (ไม่ต้องใส่ `@`) — พิมพ์แล้วกด Enter

โปรแกรมจะเริ่มทำงานทันทีและโชว์ 2 ลิงก์ประมาณนี้:

```
เปิดใช้งานที่ http://localhost:3939
- เปิดลิงก์นี้ในเบราว์เซอร์ปกติเพื่อดูแชท/ตั้งค่า
- เพิ่ม http://localhost:3939/?obs=1 เป็น Browser Source ใน OBS เพื่อให้เสียงเข้าสตรีม
```

## หน้าควบคุม (เปิดในเบราว์เซอร์ปกติ เช่น Chrome)

เปิดลิงก์แรก (`http://localhost:3939`) ในเบราว์เซอร์ตามปกติ จะเห็น 2 แท็บ:

- **แชท**: กล่องข้อความเลื่อนดูได้ โชว์คอมเมนต์ที่อ่านออกเสียงไปแล้วทั้งหมด
- **ตั้งค่า**: ปรับเสียง (ชาย/หญิง), รูปแบบข้อความ (ชื่อ+ข้อความ หรือ ข้อความอย่างเดียว), ความยาวข้อความสูงสุด, จำนวนคิวสูงสุด, บล็อก username, และคำที่ไม่อ่านออกเสียง — กด **บันทึก** มีผลทันทีโดยไม่ต้องปิดโปรแกรม

> หน้านี้**ไม่เล่นเสียง** เป็นแค่หน้าดูแชท/ตั้งค่าเฉยๆ (กันเสียงซ้อนกับ OBS)

## เพิ่มเสียงเข้า OBS (ทำครั้งเดียว)

1. เปิด OBS Studio
2. ที่ช่อง **Sources** กดปุ่ม `+` แล้วเลือก **Browser** (หรือ "Browser Source")
3. ตั้งชื่อตามใจ เช่น "ChatDiWa" แล้วกด OK
4. ในช่อง **URL** ใส่ลิงก์ที่สอง (มี `?obs=1` ต่อท้าย) เช่น `http://localhost:3939/?obs=1`
5. กด OK — เสร็จแล้ว! เวลามีคอมเมนต์เข้ามา เสียงจะเข้าสตรีมของคุณโดยอัตโนมัติ ปรับระดับเสียงได้จาก mixer ของ Source นี้เหมือน source อื่นๆ ใน OBS ปกติ
6. อยากซ่อนไม่ให้ขึ้นจอ: กดไอคอนรูปตา (👁) ข้าง Source นี้เพื่อปิดการแสดงผล **เสียงยังออกปกติ** (ไม่ต้องลบ Source)

> ต้องใช้ URL ที่มี `?obs=1` สำหรับ OBS เท่านั้น (ต่างจากลิงก์หน้าควบคุม) ไม่งั้นจะไม่มีเสียงออก
>
> ไม่ต้องลง VB-CABLE หรือปรับ audio device ในเครื่องเลย เพราะ OBS จะจับเสียงจากหน้าเว็บนี้ตรงๆ

## ใช้งานระหว่างสตรีม

- โปรแกรมจะอ่านทุกคอมเมนต์ที่มีคนพิมพ์เข้ามาในไลฟ์ของคุณอัตโนมัติ
- ปรับตั้งค่าได้ทุกเมื่อจากหน้าควบคุมในเบราว์เซอร์ ไม่ต้องแตะ Terminal เลย
- กด `Ctrl+C` ใน Terminal เพื่อปิดโปรแกรม

## ถ้าเชื่อมต่อไม่ติด

- เช็คว่าคุณ**กำลังไลฟ์อยู่จริง**บน TikTok ตอนรันโปรแกรม (โปรแกรมเชื่อมต่อกับไลฟ์ที่กำลังสดเท่านั้น)
- เช็คว่าใส่ username ถูกต้อง (ดูจาก URL หน้าโปรไฟล์ TikTok ของคุณ ไม่ต้องมี `@`)
- โปรแกรมจะพยายามเชื่อมต่อใหม่ให้อัตโนมัติถ้าหลุดกลางคัน ไม่ต้องรีสตาร์ทเอง

## ตั้งค่าใหม่ตั้งแต่ต้น

ลบไฟล์ `chatdiwa.config.json` ในโฟลเดอร์ที่รันคำสั่ง แล้วรัน `npx github:Babyferret/chatdiwa` ใหม่อีกครั้ง โปรแกรมจะถาม username ใหม่ (ตั้งค่าที่เหลือปรับได้จากหน้าเว็บตามปกติ)
