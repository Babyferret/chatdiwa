ChatDiWa - TikTok LIVE chat-to-speech reader
==============================================

How to use:
1. Double-click run.bat in this folder.
2. If Node.js isn't installed, the script will ask before installing it.
3. A control panel window will open automatically in your browser.

Every time you run run.bat, it re-downloads the latest version from
GitHub automatically - you never need to redownload this zip to get
updates, only if this launcher script itself changes.

Full documentation (Thai):
https://github.com/Babyferret/chatdiwa

You can move this whole "ChatDiWa" folder anywhere you like (Desktop,
etc.) - just keep run.bat together with this file.
